CHRONOS website attribution

The extension reports only the domain of the active tab to the CHRONOS desktop app on this machine (127.0.0.1). No URLs, titles, or page content are ever read or sent, and nothing leaves your computer.

“Pair automatically” opens the local CHRONOS pairing page, which stores the token for this extension by itself. You can also pair by opening this page with the token in the address bar (options.html#token=…) — the token is consumed and removed from the URL immediately.
